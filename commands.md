# clone
creates a local version of a repo
# Checkout
switches to some other branch
- -b: creates a new local branch and immediately switches to it
# status
used to display the current state of work
# push
- -u: orgin branch name to push a branch for the first time
# pull
used to update your local repository
# add
the command used to move changes from your working directory to the staging area
# commit 
- -m "your message" permanently saves your staged code changes to your local project repository history.
- -a automatically stages modified and deleted tracked files before performing a commit
- -am "your messgae" is a shortut that combines two distinct git actions into a single step.
# branch 
- -a lists all local and remote-tracking branches available in your current repository
- -d command deletes a local git branches safely, preventing you from losing unmerged code.
# merge 
command combines the commit history and changes from one git branch into your current active branch.
